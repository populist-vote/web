## Introducing: The Populist public API

The Populist public API provides access to the Populist platform's features and
data. You can use the API to consume data about elections, politicians, bills,
and more.

Populist supports two API styles:

- **GraphQL** for clients that need flexible queries across the complete data
  graph.
- **REST** for common datasets with stable, resource-oriented request and
  response contracts.

### GraphQL

Use GraphQL to request exactly the fields your application needs.

A query to the Populist API could looks something like this:

<CodeBlock
  code={`query {
    elections(filter: { state: CO }) {
      title
      description
      electionDate
    }
}`}
  language="graphql"
/>

### REST

The versioned REST API is available under `/api/v1`. Resource-oriented GET
endpoints support election discovery, race and ballot-measure reporting, and a
lightweight election-night results feed:

<CodeBlock
  code={`GET https://api.populist.us/api/v1/elections?state=MN&year=2026`}
  language="http"
/>

Start with the [REST overview](/docs/api/rest), then use the
[election-data guide](/docs/api/election-data) for newsroom reporting workflows
or the [ballot-by-address guide](/docs/api/ballot-by-address) for
address-specific coverage.
