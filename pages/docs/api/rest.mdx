## REST API

The Populist REST API provides stable, resource-oriented access to common
datasets. Use it when your integration does not need GraphQL's field-level query
control.

The production base URL is:

<CodeBlock code={`https://api.populist.us/api/v1`} language="http" />

Use the environment URL and a bearer API key created from
[My Profile](/settings/profile). The same key can call GraphQL. All examples
below use production for clarity; see [Authentication](/docs/api/auth) for key
creation, rotation, and revocation.

### Successful responses

Dataset endpoints use a top-level `data` envelope. Collection endpoints can
also include `meta` pagination information.

Every REST response includes `X-Request-Id`. Send your own opaque value, or let
Populist generate one. Keep that ID in application telemetry because it is the
best value to provide when troubleshooting. Do not put an address, email, token,
or other personal data in it.

### Errors

REST errors use `application/problem+json` with a stable machine-readable
`code`:

<CodeBlock
  code={`{
  "type": "about:blank",
  "title": "Unprocessable Entity",
  "status": 422,
  "code": "invalid_address",
  "detail": "The address could not be resolved to a voting location.",
  "instance": "/api/v1/elections/7f7f1111-2222-4333-8444-555555555555/ballot"
}`}
  language="json"
/>

Branch on the HTTP status and `code`, not the human-readable `title` or
`detail`. Correct 400, 404, 405, 413, 415, and 422 responses before trying
again. Retry 429, 503, and 504 responses only with a bounded exponential
backoff and jitter. Honor `Retry-After` when it is present.

### HTTP conventions

- Send and accept JSON with `Content-Type: application/json` and
  `Accept: application/json`.
- Treat IDs as opaque UUID strings.
- Ignore response fields your client does not recognize.
- Handle new enum values defensively.
- Do not use titles or slugs as stable identity.
- Use HTTPS for every request.
- Do not cache responses marked `Cache-Control: no-store`.
- For cacheable GET resources, honor the response `Cache-Control` freshness
  and stale-while-revalidate directives.

### Versioning

The major API version is part of the path. Breaking changes require a new major
path such as `/api/v2`. Additive fields and enum values can be introduced
within v1, so clients should be tolerant readers.

### Available datasets

- [Election Data](/docs/api/election-data): discover elections, browse races
  and ballot measures, and poll a compact election-wide results feed.
- [Ballot by Address](/docs/api/ballot-by-address): resolve election, race,
  candidate, result, and ballot-measure data for a US address.

The machine-readable contract is available as
[OpenAPI 3.1](/openapi/rest-v1.yaml).
